# FPSO Equipment Monitoring

This repository contains code and resources for monitoring equipment on FPSO (Floating Production Storage and Offloading) vessels.

## Contents

- **notebook/**: Contains notebooks for Exploratory Data Analysis (EDA) and model exploration.
- **main.py**: Entry point to run the complete data processing and modeling pipeline.

## Usage

1. Explore the data and models using the provided notebooks.
2. Run the pipeline with:

    ```bash
    python main.py
    ```

## Requirements

See `requirements.txt` for dependencies.
